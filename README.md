Project: Advanced AI Voice Chatbot (Python, NLP, Speech Recognition)
Description:
Built an intelligent voice-enabled AI chatbot using Python with NLP, speech recognition, text-to-speech, Wikipedia search, and smart system commands.
Technologies: Python, SpeechRecognition, Pyttsx3, Wikipedia API, NLP
Features:
•	Voice input & voice reply
•	Searches information using Wikipedia
•	Opens websites on command
•	Gives real-time date & time
•	Tells jokes & interacts naturally
•	Modular architecture
Outcome: Developed an AI assistant capable of performing real-time tasks using speech-based NLP.

(Speech + Voice Output + Wikipedia + Smart Commands)

procedure---------------------------------------------------------------------------------------------
Step 1: Install required libraries
Run these commands one by one in Terminal / CMD / VS Code:
pip install speechrecognition
pip install pyttsx3
pip install wikipedia
pip install pyaudio

Step 2: Create file → advanced_chatbot.py
STEP 3 — Plug in your Microphone
Because the chatbot listens to your voice.
Laptop mic also works.
STEP 4 — Run the chatbot
In VS Code Terminal or CMD:
----->python advanced_chatbot.py
STEP 5 — Talk to your chatbot
After running, you will see:
Listening...
Now say things like:
•	Hi
•	Tell me a joke
•	What is the time
•	Search Virat Kohli
•	Open YouTube
•	Bye
